# 📊 HR Attrition Analytics Dashboard

An interactive Excel dashboard built to analyze employee attrition, workforce demographics, and turnover trends. This project demonstrates data cleaning, PivotTables, PivotCharts, slicers, KPIs, and dashboard design using Microsoft Excel.

## 📌 Features

- Interactive slicers and timeline
- KPI cards for key HR metrics
- Employee attrition analysis
- Department-wise employee distribution
- Exit reason analysis
- Employee joining trend
- Gender distribution
- Age group distribution
- Tenure distribution
- Department-wise attrition comparison

## 📈 Key KPIs

- 👥 Total Employees
- 🟢 Active Employees
- 🔴 Exited Employees
- 📉 Attrition Rate
- ⏳ Average Tenure
- 🎂 Average Age

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline
- Conditional Formatting
- Excel Formulas

## 🎯 Project Objective

To create an interactive HR analytics dashboard that helps analyze employee turnover, workforce demographics, and attrition trends for better business insights.
