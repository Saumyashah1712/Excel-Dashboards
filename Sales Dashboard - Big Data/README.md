# 📊 Sales Performance Dashboard

An interactive **Sales Performance Dashboard** built in **Microsoft Excel** using Pivot Tables, Pivot Charts, Slicers, and Timelines. It provides insights into sales, products, customers, regions, and promotions through dynamic visualizations.

## ✨ Features

- Interactive Timeline & Slicers
- KPI Cards
- Monthly Sales & Orders Analysis
- Product & Regional Performance
- Top Salesperson Analysis
- Payment Method & Promotion Analysis
- Shipping Cost & Discount Analysis
- Dynamic Pivot Charts

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Timeline
- Excel Formulas

## 📊 KPI Metrics

- 💰 Total Sales
- 📦 Total Orders
- 🛒 Total Quantity
- 👥 Total Customers
- ↩️ Return Rate
- 🚚 Shipping Cost
